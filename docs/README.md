# 백엔드 문서 안내

마지막 수정일: 2026-06-24

이 폴더는 `dev/bike-back` 저장소 안에서 백엔드 구현자가 바로 참고해야 하는 문서만 둔다.
세션 완료 보고서, QA 보고서, 프롬프트 전달용 보고서는 먼저 워크스페이스 루트의 `session-handoff/<세션>/reports/` 아래에 남긴다.
장기 보관할 최종본만 루트 `reports/`로 승격한다.

## 폴더 기준

| 위치 | 역할 |
|---|---|
| `ADR/` | 백엔드 기술 선택, 구조 선택, 성능 개선 판단 기록 |
| `검토/` | 기능별 리뷰, 아키텍처 리뷰, 개선 후보 정리 |
| `계획/` | 이미 완료됐거나 보존 가치가 있는 구현 계획 |
| `인프라/` | 로컬 런타임, Docker Compose, AWS, k6, GitHub 동기화 가이드 |

## 보고서 위치

백엔드 세션을 포함한 모든 채팅 세션의 1차 실행 보고서는 `session-handoff/<세션>/reports/`에 둔다.

| 세션 | 기본 위치 |
|---|---|
| 메인/백엔드 세션 | `../../../session-handoff/main-backend/reports/` |
| 프론트 세션 | `../../../session-handoff/frontend/reports/` |
| 리뷰/QA 세션 | `../../../session-handoff/review-qa/reports/` |
| 프롬프트 세션 | `../../../session-handoff/prompt/reports/` |

`dev/bike-back/docs/`에는 새 `*-report-YYYY-MM-DD.md` 파일을 만들지 않는다.
검증 원본 로그나 큰 evidence는 `ARTIFACTS/`에 두고, 사람이 반복해서 읽을 최종 요약 보고서만 루트 `reports/`로 승격한다.
